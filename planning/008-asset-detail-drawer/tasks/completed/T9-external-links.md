## Description

A small menu beside the ticker in the drawer header linking out to Yahoo Finance, Google Search
and TradingView.

## Implementation guidance

From spec decisions D6, D10, D11 and `plan.md` → ADR *external links from the ticker alone*.

Render from `externalLinksFor(asset)` (T2). If it returns `[]`, render nothing — no disabled
menu, no empty affordance.

**Securo links, it never reads.** No request to any third party, no API key, no parsing, no
caching, no third-party figure rendered inside Securo. The whole feature is URL construction
plus an anchor.

**Why these three.** Quotes come from `yfinance` (`app/providers/market_price.py`), so
`Asset.ticker` *is* a Yahoo symbol — `AAPL`, `PETR4.SA`, `HGLG11.SA`, `BTC-USD` — and Yahoo
needs no translation. Google Search cannot 404 and shows Google's own finance card at the top
of results. TradingView covers charts and indicators; its suffix-stripping is a heuristic whose
failure mode is a search page instead of a chart, which is why Google Search is in the set.

**Google Finance deep links are rejected** and must not be added: `/finance/quote/{SYMBOL}:{EXCHANGE}`
needs Google's own exchange codes (`BVMF`, `NASDAQ`) while `ticker_exchange` holds Yahoo's
display strings (`NasdaqGS`, `São Paulo`). Any mapping between them is a permanent source of
silent 404s.

**Markup requirements** — `target="_blank"` and `rel="noreferrer"` on every link, matching the
existing external links in the codebase (`token-connect-dialog.tsx`, `oauth-callback.tsx`).
Links must be visibly external and visibly third-party (the `ExternalLink` icon from
`lucide-react` is already used elsewhere for this), so a user cannot mistake the destination
for a Securo screen.

**Exclusions** are T2's business, but verify them here: manual assets, growth-rule assets, and
`TD:`-prefixed Tesouro Direto symbols get no links. `TD:<hash>:<maturity>` is a synthetic
identifier generated by `tesouro_direto.tesouro_symbol_for` and is meaningless outside Securo.
Do **not** reuse this exclusion for T12's filter — a `TD:` symbol is a perfectly good filter
key.

## Outcome

`ExternalLinksMenu.tsx`, in the drawer header beside the close button, built on the existing
`components/ui/dropdown-menu` rather than a hand-rolled popover. Renders `null` when
`externalLinksFor` returns `[]`, so a manual asset or a Tesouro Direto bond shows no affordance
at all — not a disabled one.

The menu carries a label saying it opens a third-party site in a new tab, so the destination
cannot be mistaken for a Securo screen. Every anchor has `target="_blank"` and
`rel="noreferrer"`, matching `token-connect-dialog.tsx` and `oauth-callback.tsx`.

The URL construction and all four exclusions were already covered by T2's tests, so this task
added no new ones — it is markup over a tested function.

Two locale keys across nine files. Provider names (Yahoo Finance, TradingView, Google) are
proper nouns and stay untranslated.
